# Backstore

Archived sources for future hosting on this site. Nothing here is linked from the site yet.

- `paper_latex/`: arXiv LaTeX source and arXiv PDF for every paper in `pub.html` with an
  arXiv link. All of them compile; see `paper_latex/README.md`.
- `project_pages/`: copies of the first-author project pages (ABC123, MCAC, Learning to
  Count Anything) from the ActiveVisionLab `gh-pages` branches.
- `thesis/`: final DPhil thesis PDF plus unpacked LaTeX source that rebuilds it.

Every file is under GitHub's 100 MB limit; the largest is the 68 MB thesis PDF.
